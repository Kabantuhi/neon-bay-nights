Neon Bay Nights is a GTA 6-style open-world crime game that plays offline in a desktop browser: explore the city on foot and by car, steal cars, outrun the police as your wanted level rises, run missions, fight, and save your progress.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.
